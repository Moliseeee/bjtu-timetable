# 北交大 2026-2027-1 学期课表 iCal

把北京交通大学教学支撑平台的选课课表转成 iCalendar（.ics）文件，导入手机/电脑日历后即可在日历里看课、并可订阅自动更新。

写这个是因为教务系统的课表只能在网页看，手机日历原生日程更顺手。数据来源是本学期选修课表截图，逐格整理而成。

## 内容

- 校本部常规上课时间（第 1-7 节），时区 Asia/Shanghai
- 节次时间：1 节 08:00-09:50 / 2 节 10:10-12:00 / 3 节 12:10-14:00 /
  4 节 14:10-16:00 / 5 节 16:20-18:10 / 6 节 19:00-20:50 / 7 节 21:00-21:50
- 支持限定周次（如某课只上周 9-16 周）、双周课、同一门课一周多次
- 节假日停课统一按校历剔除（中秋国庆连放、校庆日等），不产生错课
- 每次课在日历里带课程号、教师、周次、教室

## 用法

### 方式一：订阅（推荐，改动自动同步）

iPhone：设置 → 日历 → 账户 → 添加账户 → 其他 → 添加已订阅的日历 → 粘贴：

```
https://cdn.jsdelivr.net/gh/Moliseeee/bjtu-timetable-freshman@main/bjtu-timetable-2026-2027-1-freshman.ics
```

> 仓库需保持 public，改成 private 后匿名订阅会失效。

### 方式二：一次性导入

下载 `bjtu-timetable-2026-2027-1-freshman.ics`（本仓库文件或 Release 附件），
在手机/电脑上直接打开 → 添加到日历。

建议先在日历 App 里新建一个「课表」日历，导入时选中它，以后整组删除很方便。

## 自己改课表

课表数据都在 `gen_timetable_ics.py` 里，改完重跑即可：

```bash
python gen_timetable_ics.py --start 2026-09-07   # 第 1 周周一
```

- `COURSES`：`(周几 1=周一..7=周日, 节次, 起周, 止周, 间隔)`；间隔 2 = 隔周课，
  注意**隔周课从哪一周起算要写对**（如「第 2,4,…,16 周」应写 `(4, 5, 2, 16, 2)`，
  写 `1` 会错成 1,3,5…15 周）
- `LOCATIONS`：课程 + 节次的教室映射
- `NO_CLASS_DATES`：停课日期（落在其中的课自动剔除）
