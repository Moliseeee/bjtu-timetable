# BJTU 课表 iCal

北京交通大学 2026-2027-1 学期课表，转成 Apple 日历可读的 `.ics` 文件，供个人 iPhone 日历订阅/导入使用。一个顺手做的小工具，代码也一并放在这里，方便下学期复用。

## 文件

| 文件 | 说明 |
|---|---|
| `bjtu-timetable-2026-2027-1.ics` | 本学期课表（iCalendar 格式，重复事件规则展开，共 20 组） |
| `gen_timetable_ics.py` | 课表 → ICS 生成脚本（课程数据在脚本内，改课直接改数据重跑） |

## iPhone 订阅

设置 → 日历 → 账户 → 添加账户 → 其他 → 添加已订阅的日历，粘贴：

```
https://cdn.jsdelivr.net/gh/Moliseeee/bjtu-timetable@main/bjtu-timetable-2026-2027-1.ics
```

内容更新后，在日历 App 里下拉即可刷新。

也可以直接下载 `.ics` 文件到手机点开，一次性导入日历。

## 重新生成

新学期/调课后改脚本里的课程数据，重跑：

```bash
python gen_timetable_ics.py --start 2026-09-07   # --start 填第 1 周周一
```

## 说明

- 时间按北京时间存储（UTC+8），出国时差场景下以日历换算为准
- 特殊周次规则已按课表处理：单双周（隔周）、限定期次（如仅 1-8 周 / 9-16 周）的课程都转成了对应的重复规则
- 课程信息（教师、教室）来自教务系统课表，如与教学安排有出入以教务系统为准
